---
name: metabrain-defuddle
description: Preview capture of an HTTP or HTTPS URL without fetching it, or capture already supplied HTML or Markdown into a metaBrain wiki.
---

- For a URL preview, first check for sensitive credentials or signed or bearer parameters. Ask for a safe provenance URL when needed and keep the sensitive string out of terminal calls, previews, and notes. For an ordinary URL, run `python3 scripts/plan-url.py -- 'URL'` relative to this skill's directory. Present the origin, the need for an original HTML or Markdown file, and the proposed project and source-note destination if known. Say that the URL has not been fetched. A preview makes zero outgoing requests, including DNS and redirect checks. MetaBrain has no built-in URL fetcher. If the user requests retrieval, use an authorized host tool only within its authorized scope. Label only exact response bytes as the original. Request a supplied original if the tool cannot provide those bytes.
- For locally supplied HTML or Markdown, preview from the file without contacting the origin. Skip `mb source stage` on preview. Treat HTML as inert input and keep embedded resources unloaded. Use the file as supplied and record its safe declared URL as provenance, or use its local origin if no URL was supplied. Identify the selected wiki via the [CLI skill](../metabrain-wiki-cli/SKILL.md).
- On a request to capture, use the [ingest skill](../metabrain-wiki-ingest/SKILL.md). Pass the original file to `mb source stage FILE --origin ORIGIN --media-type TYPE` using the selected connection. Use `text/html` or `text/markdown` as applicable. Preserve the exact bytes, including encoding and line endings. If the user requests extraction, run a verified local method on the supplied bytes with networking and rendering disabled. Keep the resulting text in the source note and add `--extraction METHOD` to staging only when that method actually ran successfully. Record what ran and report extraction limits. Markdown may be copied faithfully into the source note without an extraction marker. For HTML without extraction, leave the source body empty. Check the staged digest and use the returned capture in the reviewed operation. Recover the original with `mb source export PATH --version N --output FILE`.
